## Caso D
Problema identificado: type="correo", ya que el tipo de dato se nombra en ingles y faltaria el id que es para poder reconocerlo de forma más rapido en el programa.
Corección realizada:
<form>
    <input type="email" id="correo" name="correo">
</form>
Fuente consultada: https://youtu.be/Mcktcj8xOOo
